# K-POP 공연장 관리 프로그램 과정평가형 문제 검토 의견

## 종합 의견

가장 눈에 띄는 것은 1번(요구사항 서두의 "주차 관리 프로그램" 문구)과 3번(서로 다른 두 벌의 테이블 생성 스크립트가 폴더에 공존)입니다. 1번은 문제지가 다른 원형문제(주차 관리)를 복사해서 만들다가 지우지 않은 문구로 보이므로, "K-POP 공연장 예매 관리 프로그램을 작성하시오"처럼 실제 과제명에 맞게 고치는 게 좋겠습니다. 3번은 `sql` 파일이 `ADRESS` 오타, 복합키 설계, 잘못된 `TO_DATE` 포맷 등 이미 폐기된 것으로 보이는 구버전 내용을 그대로 담고 있어서, 만약 이 파일이 실수로 실행되면 명세서와 다른 스키마가 만들어질 위험이 있습니다. 실습/채점 환경에서 어떤 파일을 기준으로 삼을지 정리(예: `sql` 파일 삭제 또는 `archive/`로 이동)해 두시는 것을 권합니다.

4번(결재/결제 용어)과 5번(유효성 메시지 문구 미명시)은 문제지 자체의 완성도 이슈이며, 다행히 현재 소스는 각 화면의 참고 이미지와 정확히 맞게 구현돼 있어 실제 동작상 문제는 없습니다. 나머지(2, 6, 7, 8번)는 경미하거나 이미 해결된 사항입니다.
